## Sobre o projeto
Este projeto foi desenvolvido como parte de um desafio de Onboarding para testar e aplicar conhecimentos em estruturação web e estilização. O objetivo foi transformar um layout disponibilizado no Figma em uma página web totalmente funcional e responsiva, construindo o código do zero.

Como diferencial (Desafie-se), foram criadas páginas extras conectadas por uma jornada de compra que leva o usuário até um carrinho de compras simulado.

## Layout de Referência
O layout que serviu de base para a construção da interface pode ser visualizado no [Figma](https://www.figma.com/design/50IIf5AGtx4uBF8U5qzivp/Primeira-atividade-Onboarding-HTML---CSS?node-id=0-1&t=d5HlPXuIjzkmOZZO-0).

## Tecnologias Utilizadas
A regra principal do desafio foi o uso restrito de tecnologias base:
- **HTML5**: Estruturação semântica das páginas.
- **CSS3**: Estilização, variáveis globais, Flexbox, CSS Grid e media queries.

## Funcionalidades e Diferenciais
- **Responsividade Total**: Layout adaptado para Mobile e Desktop (Mobile First).
- **Múltiplas Páginas**: Além da Home, foram desenvolvidas as páginas de Menu, Lojas, Gift Cards, Recompensas e Carrinho.
- **Fidelidade Visual**: Efeitos aplicados via CSS puro para igualar o design (textos com efeito vazado em neon, botões com hover e animação de flutuação no elemento 3D).

## Como rodar o projeto localmente
Caso queira baixar o código-fonte e rodar na sua máquina:

1. Faça o download deste repositório clicando em `Code` > `Download ZIP` (ou faça o clone via Git).
2. Extraia os arquivos no seu computador.
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador padrão.
4. Navegue pelos links do cabeçalho e clique nos botões para testar as conexões entre as páginas.
