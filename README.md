# Desafio-Great-Coffee
O "Great Coffee" é um projeto front-end de onboarding criado para testar habilidades em HTML5 e CSS3 puros. Baseado no modelo Mobile First, o desafio exigiu a criação de um site responsivo fiel a um layout do Figma, sem frameworks. A aplicação possui tema tech neon e conta com páginas de Menu, Lojas, Fidelidade, Gift Cards e Carrinho simulado.
